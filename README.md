# 会議メモ整理アプリ

会議内容、決定事項、TODO を登録して、あとから必要な情報を探しやすくする Web アプリです。

## 初回実装の範囲

- React / TypeScript / Vite のフロントエンド土台
- 会議メモの一覧表示
- 会議メモの新規登録
- 会議メモの詳細表示
- 会議メモの編集と削除
- タイトル、参加者、本文、決定事項、TODO を対象にしたキーワード検索
- タグによる絞り込み
- TODO の担当者、期限、完了状態の管理
- ブラウザの localStorage への保存

## 今後の拡張予定

- FastAPI バックエンドの追加
- SQLite への永続保存
- API 経由の登録、更新、削除
- デプロイ環境の整備

## セットアップ

```bash
pnpm install
pnpm run dev
```

## ビルド

```bash
pnpm run build
```
